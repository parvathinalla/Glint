Local pose tracking uses @mediapipe/tasks-vision 1.2.0 (Apache-2.0 npm package).
Generated JavaScript/WASM runtime files are copied from that pinned dependency by scripts/prepare-vision.mjs.

Pose Landmarker Lite model, float16 revision 1, downloaded from Google's official model distribution:
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task

SHA-256: 59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a

Documentation and upstream terms: https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker
Model inference runs locally; camera pixels are not sent to Google by this application.
