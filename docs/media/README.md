# Glint videos

[Watch the final demo on YouTube](https://youtu.be/LNRBw1rmBLQ)

[Download the MP4](Glint-Demo.mp4)

To add another recording:

1. Upload the video to this folder, or upload it to YouTube.
2. Add its title and link under **More Glint videos** in the root README.
3. Keep the final demo above the additional recordings.

For large clips, use a YouTube link to keep repository downloads smaller.
